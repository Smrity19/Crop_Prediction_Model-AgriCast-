AgriCast: Crop Prediction Model 🌾

Project Description

AgriCast is a machine learning-based predictive model designed to recommend the most suitable crops to plant based on various soil and environmental parameters. By analyzing factors such as Nitrogen (N), Phosphorous (P), Potassium (K) levels, temperature, humidity, pH, and rainfall, this project aims to empower farmers and agricultural stakeholders with data-driven decision-making tools to maximize yield and promote sustainable agriculture.

Features

Data-Driven Recommendations: Accurately predicts the optimal crop for a given set of soil and climate conditions.

Data Preprocessing: Handles missing values and scales agricultural data for optimal model performance.

Machine Learning Pipeline: Utilizes classification algorithms to map environmental inputs to the best agricultural outputs.

Scalable & Easy to Use: Simple setup process, making it accessible for further development or immediate testing.

Technologies Used

Language: Python

Data Manipulation & Analysis: Pandas, NumPy

Machine Learning: Scikit-learn

Domain: Machine Learning / Precision Agriculture

Installation

To get this project up and running on your local machine, follow these steps:

Clone the repository:

git clone https://github.com/Smrity19/Crop_Prediction_Model-AgriCast-.git


Navigate to the project directory:

cd Crop_Prediction_Model-AgriCast-


Install the required dependencies:
(Ensure you have Python installed. It is recommended to use a virtual environment.)

pip install pandas scikit-learn numpy

Usage

Open the project in your preferred IDE or Jupyter Notebook environment.

Run the main Python script or execute the cells in the Jupyter Notebook to train the model.

Input your soil and environmental parameters (N, P, K, temperature, humidity, pH, rainfall) when prompted or within the script to receive a crop recommendation.
